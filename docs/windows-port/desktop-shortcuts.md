# Windows 桌面快捷键与菜单

Flit 在 Windows 上有完整的菜单栏（文件 / 编辑 / 视图 / 运行 / 帮助）与全局快捷键。
两者共用同一套命令注册表：**页面注册了什么，菜单项就亮什么，快捷键也只对亮着的
项生效**（例如没打开工程时「保存」是灰的）。

## 1. 快捷键总表

| 键位 | 作用 | 作用域 | 对应菜单项 |
| --- | --- | --- | --- |
| `Ctrl+N` | 新建工程 | 工程列表 | 文件 → 新建工程 |
| `Ctrl+O` | 打开工程（原生文件夹选择器） | 工程列表 | 文件 → 打开工程 |
| `Ctrl+Shift+O` | 导入已有文件夹 | 工程列表 | 文件 → 导入文件夹… |
| `Ctrl+S` | 保存当前工程全部改动 | 编辑器 | 文件 → 保存 |
| `Ctrl+Shift+S` | 全部保存 | 编辑器 | 文件 → 全部保存 |
| `Ctrl+W` | 关闭当前标签 | 编辑器 | 文件 → 关闭标签 |
| `Ctrl+Alt+W` | 关闭其他标签 | 编辑器 | 文件 → 关闭其他标签 |
| `Ctrl+Shift+W` | 关闭全部标签 | 编辑器 | 文件 → 关闭全部标签 |
| —（菜单项） | 关闭工程 | 编辑器 | 文件 → 关闭工程 |
| `F5` | 运行（Web 预览 / 设备） | 编辑器 | 运行 → 运行 |
| `Shift+F5` | 停止运行 | 编辑器 | 运行 → 停止 |
| `Ctrl+Shift+B` | 打开构建面板 | 编辑器 | 运行 → 重新构建 |
| `` Ctrl+` `` | 显示/隐藏终端 | 编辑器 | 视图 → 终端 |
| `Ctrl+B` | 显示/隐藏文件树侧栏 | 编辑器 | 视图 → 文件树 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 下一个 / 上一个标签 | 编辑器 | — |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | 放大 / 缩小 / 实际大小（编辑器字号） | 编辑器 | 视图 → 放大/缩小/实际大小 |
| `Ctrl+Shift+P` | 命令面板（占位） | 全局 | 视图 → 命令面板 |
| `F1` | 快捷键说明对话框 | 全局 | 帮助 → 快捷键 |
| `F11` | 全屏切换 | 全局 | 视图 → 全屏 |
| `Alt+F4` | 退出（关窗前自动保存缓冲区） | 全局 | 文件 → 退出 |
| `Ctrl+,` | 设置 | 全局 | 视图 → 设置 |

编辑菜单里的 撤销/重做/剪切/复制/粘贴/全选 走 Flutter 标准文本意图，作用在
当前获得焦点的输入框/代码编辑区上（未聚焦时这些项不生效，符合 Windows 习惯）。

## 2. 鼠标与键盘约定

- **侧栏**：窗口宽度 ≥1000 时是永久左侧栏（可拖右缘 220–420 调整宽度），`Ctrl+B` 收起。
  更窄时回落到手机式的抽屉。
- **工程列表**：单击选中、双击打开、`↑`/`↓` 移动、`Enter` 打开、`Delete` 移除；
  右键菜单含「打开 / 在资源管理器中显示 / 复制路径 / 重命名 / 删除」。
- **文件树**：单击展开目录/打开文件，右键同上的文件操作菜单，行高按桌面收紧。
- **标签**：中键或 `✕` 关闭，右键「关闭 / 关闭其他 / 关闭全部」。
- **缩放**：编辑器与终端支持 `Ctrl+滚轮`；终端还保留手机的双指缩放。
- **对话框**：桌面用居中对话框（`Esc` 关闭、`Enter` 提交），窗口窄于 600 逻辑像素时
  自动回落到手机式底部抽屉。
- **窗口**：默认 1280×800，最小 960×640，关闭时记住大小/位置/最大化；标题显示
  「<工程名> — Flit」，未打开工程时是「Flit」。

| 菜单栏 + `Shortcuts`/`Actions` | `lib/core/desktop/desktop_app_shell.dart` |
| 窗口几何/最小尺寸/标题/关窗前保存 | `lib/core/desktop/window_frame.dart` |
| 自适应对话框 | `lib/core/desktop/desktop_presentation.dart` |
| 悬停/右键行 | `lib/core/desktop/hover.dart` |
| 滚动条行为 | `lib/core/desktop/scroll_behavior.dart` |

| 原生文件夹/另存为/资源管理器 | `lib/services/native_file_service.dart` |
| 桌面文案 | `lib/l10n/desktop_strings.dart` |
| 宽屏侧栏/工具条/状态栏 | `lib/features/editor/widgets/desktop_*.dart` |
| 桌面工程列表 | `lib/features/projects/desktop_projects_view.dart` |
